How to set this up (one time only)

1
Go to Google Cloud Console
Open console.cloud.google.com and sign in with your Google account.
2
Create a new project
Click the project dropdown at the top → "New Project" → give it any name → Create.
3
Enable the Google Sheets API
Go to "APIs & Services" → "Enable APIs" → search for "Google Sheets API" → click Enable.
4
Create a Service Account
Go to "APIs & Services" → "Credentials" → "Create Credentials" → "Service account" → fill in a name → Done.
5
Download the JSON key
Click your new service account → "Keys" tab → "Add Key" → "Create new key" → JSON → it will download a file. That's what you upload here.
6
Share your Google Sheet with the service account
Open your Google Sheet → Share → paste the service account email (it looks like something@project-name.iam.gserviceaccount.com, found inside the JSON file) → set to Viewer → Share.
7
Highlight rows green & import
In your sheet, highlight any row green that you want imported. Then come back here and click Import.
Your sheet columns: name · website · phone · address · city · categories · review_count · rating · status · place_id · state · query
Make sure your sheet has these exact column headers in the first row.
