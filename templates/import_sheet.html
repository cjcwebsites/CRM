One-time setup (5 minutes)

1
Go to Google Cloud Console
Open console.cloud.google.com and sign in.
2
Create a project
Click the project dropdown → New Project → give it any name → Create.
3
Enable Google Sheets API
APIs & Services → Enable APIs → search "Google Sheets API" → Enable.
4
Create a Service Account
APIs & Services → Credentials → Create Credentials → Service account → fill in a name → Done.
5
Download the JSON key
Click your service account → Keys tab → Add Key → Create new key → JSON. A file downloads — that's what you upload here.
6
Share your sheet with the service account
Open your Google Sheet → Share → paste the service account email (inside the JSON file, it's the client_email value) → Viewer → Share.
7
Highlight rows green and press Start Live Sync
Green rows appear in Companies within 30 seconds. Remove the highlight and they disappear.
